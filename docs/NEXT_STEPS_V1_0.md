# Next Steps: AZM-QOS v1.0

Recommended v1.0 milestone:

## Integrated Research Demonstration

Connect:

```text
azmqos_endvqs
+
azmqos_qec
+
error management
+
backend selector
```

into one complete research workflow:

1. Build END/VQS M and V workloads.
2. Map observables to logical Pauli workloads.
3. Estimate them on local/shot/Qiskit backends.
4. Assemble M and V.
5. Run uncertainty analysis.
6. Generate a manuscript-ready report.
