# AZM-QOS v2.5 Mitigation Limitations

The v2.5 mitigation layer is a scaffold.

It does not replace:

- full measurement calibration experiments
- correlated readout mitigation
- gate-noise tomography
- rigorous uncertainty propagation
- drift tracking
- randomized compiling
- problem-specific validation circuits

For publication, clearly state mitigation assumptions and validate them with calibration data.
