# AZM-QOS v4.8 Final Export Workflow Guide

The v4.8 workflow does:

1. Runs or loads the v4.7 hardware-analysis workflow.
2. Copies final figures into a publication-ready `figures/` folder.
3. Generates a summary figure.
4. Exports a LaTeX manuscript scaffold.
5. Exports a thesis appendix scaffold.
6. Writes a reproducibility checklist.
7. Writes a version lockfile.
8. Packages the final export into a ZIP archive.

Synthetic-only analyses must be labeled as workflow validation rather than hardware evidence.
