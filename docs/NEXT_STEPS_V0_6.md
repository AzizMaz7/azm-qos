# Next Steps: AZM-QOS Core v0.6

Recommended next milestone:

## Plugin System

Create separate plugin-style folders/packages:

```text
azmqos_vqs
azmqos_endvqs
azmqos_qec
```

## v0.6 features

- formal plugin registry
- VQS plugin template
- END/VQS M-matrix estimator template
- V-vector estimator template
- QEC logical observable template
- example plugin project manifest

## Why v0.6 matters

v0.5 gives us a general platform.
v0.6 turns your PhD project into a plugin rather than hard-coding it into the core.
