# AZM-QOS Plugin Templates

This folder demonstrates how future plugins can live outside the core package.

Recommended future package names:

```text
azmqos-vqs
azmqos-endvqs
azmqos-qec
azmqos-chemistry
azmqos-qaoa
```

The built-in templates currently live inside `azmqos/plugin_templates.py` for simplicity.
Once the project matures, each template can become its own installable plugin.
